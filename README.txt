ООО «ТИТАН» — версия сайта для размещения на домене

1. Загрузите содержимое этой папки в корневую папку сайта на хостинге (обычно public_html, www или htdocs).
2. Главная страница уже называется index.html.
3. Подключите домен к хостингу через DNS по инструкции вашего хостинг-провайдера.
4. Выпустите бесплатный SSL-сертификат (HTTPS) в панели хостинга.
5. После выбора домена добавьте его в canonical, Open Graph URL и sitemap.xml.
6. Кнопки заявки сейчас открывают почтовую программу и отправляют запрос на Titan_777@internet.ru. Для формы без почтовой программы потребуется обработчик формы на сервере или внешний сервис.
